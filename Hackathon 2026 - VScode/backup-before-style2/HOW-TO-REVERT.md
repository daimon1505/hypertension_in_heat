# How to undo the warm/sidebar restyle (Style sample 2)

These are the files exactly as they were before the restyle of 2026-09-20.
To go back, run this from the project folder:

    cp backup-before-style2/style.css site/css/style.css
    cp backup-before-style2/ui.js     site/js/ui.js
    cp backup-before-style2/map.js    site/js/map.js
    cp backup-before-style2/index.html site/index.html

Then refresh the browser. No page content changed, so that is the whole undo.
